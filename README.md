# Game Feed

A swipe-up feed of mini-games. See **[LEDGER.md](LEDGER.md)** for every game and where to play it.

- `games.json`: the official list of games
- `games/<id>/index.html`: each game
- `LESSONS.md`: how the games are built and what every new game must get right
- `tools/check.py`: loads every game and checks for problems (runs automatically on GitHub)
